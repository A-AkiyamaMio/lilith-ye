# Lilith Motion Exhibition 设计规格

日期：2026-10-08

## 目标

把 `lilith-ye.vip` 完整升级为一个具有高端作品集质感的 Lilith 数字展览：首屏有强烈识别度，页面通过滚动、光标和图像层次讲述角色，而不是堆砌普通卡片。参考 Variant、MotionSites、React Bits 与 Design Prompts 的动效语言，但不复制具体页面、文案或组件。

## 体验定位

- 视觉底色：近黑、冷白、冰蓝与暗酒红；从当前浅色杂志风转为暗色数字展览。
- 核心印象：安静、精致、危险感克制，现代而非哥特素材堆砌。
- 页面节奏：巨型排版建立第一印象，人物图像承担叙事，信息随滚动逐层出现。
- 目标设备：桌面获得完整光标与景深体验；移动端保持同一气质，但取消依赖悬停的交互。

## 信息架构

### 首页 `/`

1. 全屏开场：巨型 `LILITH` 字样、角色主视觉、状态标签与双入口。
2. 展览宣言：一句核心描述配滚动数字与横向排版。
3. 三个识别点：暗红虹膜内圈、浅蓝五角星、现代日常状态。
4. 双状态预览：高马尾与披发两幅图形成对照。
5. 画廊预告与世界观入口。
6. 简洁收尾：返回顶部和下一页面动作。

### 人物 `/lilith`

采用编辑部档案布局：左侧粘性肖像，右侧分段呈现轮廓、目光、吊坠与两种状态。公开页面不显示私密提示词或档案全文。

### 画廊 `/gallery`

使用不对称画布、图像编号、悬停聚光与轻微倾斜。点击/键盘聚焦时强化当前作品，但不引入复杂灯箱依赖。

### 世界 `/world`

用章节式滚动讲述「名字、观看、边界」三个主题，并以私人档案入口的概念说明收尾；公共导航不暴露 `/archive`。

### 档案 `/archive/*`

保留六个静态路由、`noindex,nofollow` 与 Cloudflare Access 外层保护。视觉改为与公开站同源的深色控制台，但不把档案正文或私密媒体导入公共页面。

## 动效系统

- 光标光晕：只在精确指针设备启用，通过 CSS 变量跟随指针，不拦截点击。
- 入场：IntersectionObserver 驱动的渐显、位移和模糊收束。
- 图像：卡片指针倾斜、局部聚光和缓慢缩放；移动端自动回退。
- 排版：首屏巨型字轻微视差，跑马字幕持续缓慢移动。
- 页面切换：保留短暂遮罩，不做长时间强制开场。
- 所有动画必须支持 `prefers-reduced-motion: reduce`，无 IntersectionObserver 时内容立即可见。

## 技术方案

- 保留 Astro 5 静态构建，不迁移 React。
- 使用 Astro 组件、原生 TypeScript 和 CSS 自定义属性实现交互，避免引入大体积运行时。
- 新增聚光/光标与视觉框架组件；统一公共布局和档案布局。
- 图片继续使用现有已压缩资源，不复制参考站资产。
- 构建产物为 `dist/`，GitHub `main` 触发 Cloudflare Pages；必要时使用当前已认证的 Pages 部署通道直接发布。

## 可访问性与性能

- 保留 skip link、语义化标题、可见焦点与图片 `alt`。
- 动效元素不得隐藏正文；无 JavaScript时内容可读。
- 移动端最小宽度 320px，无横向溢出。
- 不增加音频自动播放、视频背景或 React/WebGL 运行时。
- 公开构建不得泄露档案提示词、登录接口、凭据或私密资源路径。

## 验收标准

- 首页、人物、画廊、世界四个公开页面形成统一且完整的展览体验。
- 六个档案路由继续生成并保持搜索引擎隔离。
- 桌面和移动布局可用，键盘操作与减少动效模式正常。
- 所有自动化测试通过，Astro 构建成功，公开产物边界扫描为零泄露。
- GitHub `main` 更新并完成线上部署验证。
